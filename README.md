# 📚 Dépôt de Contenu Boursehorus (Blog, Guides, Analyses)

Ce dépôt contient l'ensemble des contenus rédigés en Markdown/MDX pour l'application **Boursehorus**.

## 📂 Structure du Contenu
- `blog/` : Articles de blog généraux (`*.mdx`)
- `guide/` : Guides pédagogiques et académie d'investissement (`*.mdx`)
- `analyse/` : Analyses fondamentales d'entreprises (`*.mdx`)
- `authors/` : Profils des auteurs (`*.md`)

## ✍️ Rédiger un nouvel article
1. Créez votre fichier `.mdx` dans le dossier approprié (`blog/`, `guide/`, `analyse/`).
2. Renseignez l'en-tête Frontmatter (titre, date, résumé, tags).
3. Effectuez un `git commit` et `git push` sur la branche `main`.
4. Le site principal **Boursehorus** sera automatiquement mis à jour via Webhook !
